# 硬件与接线

系统使用 **PH1P35A 开发板**、SC520 摄像头、HDMI 显示设备及双轴舵机机构。FPGA 器件在当前工程报告中标为 **PH1P35MDG324**；开发板型号与芯片型号在这里分别列出，避免混淆。

## 硬件组成

| 部分 | 本项目使用方式 |
|---|---|
| PH1P35A 开发板 | 承载图像处理、目标分析与控制功能 |
| SC520 摄像头 | 通过开发板配套的 MIPI 摄像头接口采集图像 |
| HDMI 显示设备 | 显示图像、中文菜单、目标框与运行状态 |
| HDMI 音频播放设备 | 播放系统语音提示，可使用支持音频的显示设备 |
| TF 卡 | 使用板载 TF 接口读取配套语音素材；素材文件未随仓库发布 |
| 双轴舵机机构 | 接收水平轴与俯仰轴 PWM 控制信号 |
| 板载按键、拨码及数码管 | 用于菜单操作、功能切换与状态显示 |

当前工程的视频有效画面为 **1280 × 720**。这是工程配置，不把它直接等同于实测摄像头帧率或识别结果更新速度。

## 连接方式

| 连接 | 接法与用途 |
|---|---|
| 摄像头 → 开发板 | 使用配套 MIPI 摄像头接口连接 SC520 摄像头 |
| 开发板 → 显示设备 | 使用 HDMI 线连接，用于图像、菜单和状态输出 |
| 语音素材 → TF 接口 | 将已准备好的配套 TF 卡插入板载卡槽 |
| 水平舵机信号 | J1 第 1 针，对应 FPGA 封装引脚 V2 |
| 俯仰舵机信号 | J2 第 1 针，对应 FPGA 封装引脚 C18 |
| 舵机供电与地 | 按实际舵机的额定电源接线，控制端与舵机电源共地 |

两个舵机控制信号采用 **3.3 V 逻辑电平**。表中 V2、C18 是 FPGA 封装引脚名称，J1、J2 是板上连接器名称；接线时按连接器标识和针脚方向定位，不直接按芯片引脚名称找排针。

摄像头、TF 卡和 HDMI 使用开发板配套接口，不需要按 FPGA 封装引脚逐根飞线。舵机信号线与电源线应分清，舵机不能从 PWM 信号脚取电。电源正负与电压按当前实物配置确认后连接。

## 板上操作接口

菜单使用 SW1、SW2、SW3 和 KEY1～KEY4。各拨码及按键的作用见[板上操作与菜单](BOARD_OPERATION.md)。使用板载数码管时，需要按开发板设置接通其供电；当前工程的接线说明标注为 SW6 接通 DIGVCC。

这些连接说明针对本项目当前 PH1P35A 实物配置。更换板卡版本、摄像头连接线或舵机机构时，应重新核对连接器定义和电源接法。
