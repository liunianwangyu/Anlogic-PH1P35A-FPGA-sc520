# 板上操作与菜单

菜单内容依据 v2.7 功能菜单表整理，并对照当前工程中的中文菜单与操作逻辑核对。显示隐藏行为采用当前上板状态：普通菜单和直方图可隐藏，帧数、帧率、版本及延迟等常驻信息继续保留。

## 拨码与按键

| 控件 | 操作 |
|---|---|
| SW1 开启 | 打开功能菜单 |
| SW1 关闭 | 关闭功能菜单；正在修改但未确认的设置恢复为修改前状态 |
| SW2 开启 | 隐藏普通菜单、提示和直方图；图像及智能分析功能继续运行，常驻状态信息保留 |
| SW2 关闭 | 恢复普通菜单等内容的显示 |
| SW3 开启 | 原图对比，用于观察处理前后的画面差异 |
| KEY1 | 返回上一级；修改参数时取消本次修改 |
| KEY2 | 确认进入子菜单、进入参数修改或确认当前修改 |
| KEY3 | 向下选择；修改参数时减小数值或切换选项 |
| KEY4 | 向上选择；修改参数时增大数值或切换选项 |
| 所有功能拨码关闭时，单独按 KEY4 | 复位系统；关闭拨码后先松开按键，再按 KEY4 |

当前实现中，SW1 开启时，在最上级按 KEY1 会保留菜单；关闭菜单使用 SW1。菜单表中“返回上一级 / 退出菜单”的概括，在当前版本中按此操作。

当前选中的菜单项显示黄色，其他菜单项默认显示白色。选择功能项后按 KEY2 进入修改，用 KEY3、KEY4 预览选项，再按 KEY2 确认；按 KEY1 取消并恢复。长按增减键可连续调整数值。

SW2 控制显示隐藏，不等于关闭对应功能。左侧帧数、帧率、版本和视频延迟持续显示；已经打开的延迟诊断在菜单关闭时也保持显示。打开菜单时，延迟诊断面板会暂时让出显示区域，避免与菜单重叠。

## 图像效果变换

| 子菜单 | 选项 | 默认状态或操作条件 |
|---|---|---|
| 左右镜像 | 开启 / 关闭 | 默认关闭 |
| 上下翻转 | 开启 / 关闭 | 默认关闭 |
| 图像效果 | 原图、灰度、二值化、边缘检测、卡通化、区域填充、掩膜 | 按顺序循环选择 |
| 界限值调整 | 二值化阈值、边缘检测阈值 | 进入对应项目调整 |
| 区域填充与掩膜修改 → 颜色范围 | 红、绿、蓝各通道的下限与上限 | 仅在区域填充或掩膜效果下可进入 |
| 区域填充与掩膜修改 → 目标颜色 | 红、绿、蓝 | 循环选择 |
| 区域填充与掩膜修改 → 敏感度 | 宽松、适中、严格 | 循环选择 |
| 区域填充与掩膜修改 → 填充颜色 | 绿、蓝、黄、白 | 循环选择 |

这里公开的是用户可操作的选项，不包含颜色预设的内部数值或检测算法参数。

## 智能分析

| 子菜单 | 选项 | 默认状态或操作条件 |
|---|---|---|
| 目标检测识别 | 开启 / 关闭 | 默认关闭 |
| 运动物体检测 | 开启 / 关闭 | 默认关闭 |
| 目标追踪 → 追踪开关 | 开启 / 关闭 | 默认关闭 |
| 目标追踪 → 水平角度 | 调整水平轴角度 | 关闭自动追踪后可调整 |
| 目标追踪 → 俯仰角度 | 调整俯仰轴角度 | 关闭自动追踪后可调整 |
| 目标追踪 → 水平反向 | 开启 / 关闭 | 关闭自动追踪后可调整 |
| 目标追踪 → 俯仰反向 | 开启 / 关闭 | 关闭自动追踪后可调整 |
| 目标追踪 → 自动寻找 | 开启 / 关闭 | 默认关闭；追踪开启且曾锁定目标后，丢失目标可触发寻找 |
| 目标追踪 → 目标聚光 | 开启 / 关闭 | 默认关闭；追踪开启且有有效目标框时显示渐变聚光 |
| 延迟可视化 → 显示开关 | 开启 / 关闭 | 进入该页面不会自动开启显示 |
| 延迟可视化 → 清除统计 | 清除已有统计 | 按 KEY2 执行 |

目标检测、运动检测和目标追踪采用模式互斥：开启其中一项会关闭另外两项。“自动寻找”和“目标聚光”是追踪子选项，不参与三种分析模式的互斥。两项可以分别设置，实际生效依赖追踪模式及相应目标条件。延迟可视化是独立显示功能，可以配合分析模式使用。

自动追踪开启后，水平角度、俯仰角度、水平反向、俯仰反向四项暂时锁定，追踪开关、“自动寻找”和“目标聚光”仍可操作。要手动调整，先关闭自动追踪。新开关沿用 KEY3、KEY4 预览，KEY2 确认，KEY1 取消的操作；编辑期间关闭 SW1 会恢复未确认的修改。

演示自动寻找时，先让指定目标完成锁定，再将目标移出画面或暂时遮挡，观察局部扫描与重新确认后的跟踪恢复。上电未锁定目标时不会主动扫描。搜索因异常停止时保持当前位置，不强制回到起点。

演示目标聚光时，保持追踪开启并取得有效目标框，再切换“目标聚光”。框内画面保持，框外向暗背景渐变；关闭开关或开启 SW3 原图对比后恢复原显示。仅开启自动曝光、自动白平衡不会触发目标聚光。

延迟统计反映内部视频链路，不包括 CNN 完成一次识别所需的全部时间，也不包括舵机机构到位时间。显示器的像素响应时间也不在统计范围内。

## 推荐演示顺序

1. 连接摄像头与 HDMI 显示设备，上电观察图像和常驻状态。
2. 打开 SW1，用 KEY3、KEY4 选择项目，按 KEY2 进入并确认设置。
3. 在图像效果中逐项切换，配合 SW3 做原图对比。
4. 分别演示目标检测、运动检测与目标追踪，留意分析模式之间的切换。
5. 在追踪模式中开启“自动寻找”，演示已锁定目标丢失、局部扫描与重新跟踪。
6. 在有效目标框下切换“目标聚光”，对比框内画面和框外渐变背景，并用 SW3 检查原图对比。
7. 关闭 SW1 后观察目标框、机构和延迟诊断；切换 SW2，观察普通显示与常驻信息的区别。

既有实板确认、新增功能自动化记录及实板验收范围见[验证情况说明](VALIDATION.md)。视频和照片入口见[演示说明](DEMO.md)。
