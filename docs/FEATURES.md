# 功能介绍

系统围绕“看得见处理效果、看得见分析结果、能够操作和演示”组织功能。以下为面向展示的说明，不展开内部算法和参数。

逐级菜单、按键与拨码操作见[板上操作与菜单](BOARD_OPERATION.md)，硬件组成与外设连接见[硬件与接线](HARDWARE.md)。

## 图像采集与处理

SC520 摄像头负责采集画面，FPGA 完成相应图像处理并输出至 HDMI 显示设备。使用者可以通过中文菜单切换功能、调整相关选项，对照观察原始场景与处理后的变化。

曝光、白平衡及其他图像设置需要结合实际照明观察。演示时建议先固定场景，再逐项调整，便于看清每个选项带来的变化。

## 目标检测与运动检测

目标检测模式在画面中显示目标框、类别及相关提示；运动检测模式用于观察运动区域的位置变化。它们用于展示不同分析任务，不能仅凭框的位置或出现次数推算识别准确率。

## 目标跟踪与舵机控制

系统根据目标中心与画面中心的偏差，分别调整水平轴和俯仰轴的角度步长。偏差较大时逐步增大步长，靠近中心时减小步长，进入中心死区后停止调整。起步和换向采用较小步长。机构范围和方向以当前实物装配及设置为准。

目标检测、运动检测和跟踪是按模式选择的功能，本文不声称所有分析模式可同时独立运行。

## 自动寻找

开启追踪和“自动寻找”后，系统在已锁定的跟踪目标丢失时，以丢失前的云台角度为中心进行局部双轴扫描。再次发现候选目标后暂停扫描，经过停稳和连续有效结果确认，再恢复跟踪。

上电尚未锁定目标时，系统不会直接启动寻找。识别结果停止更新、搜索时间达到限制或用户退出相应模式时，系统停止搜索动作。自动寻找的操作入口见[板上操作与菜单](BOARD_OPERATION.md)。

## 目标聚光

开启追踪和“目标聚光”后，目标框内保留原画面，框外背景随距框边的距离增大而逐步变暗。菜单、文字和目标框保持叠加显示，方便同时观察目标和操作信息。

这是 FPGA 显示端的图像亮度处理，不需要新增照明器件，也不改变传感器曝光或识别输入。无有效目标框、结果发布超时或开启原图对比时，画面恢复原显示。它配合目标追踪使用，不是单独的分析模式。

## 中文交互、状态与语音

中文菜单用于选择功能及调整参数。画面提供帧数、帧率、版本与延迟等运行信息，并可查看延迟诊断；普通菜单隐藏与常驻状态显示有不同的显示行为。语音提示配合识别与系统操作展示。

延迟显示反映内部视频链路的统计，不代表从目标移动到识别完成、舵机到位的整机响应时间。
