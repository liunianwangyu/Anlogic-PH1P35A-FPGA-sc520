## 报告与烧录文件的对应关系

资源来自 `td_project/camera_to_dsi_display_Runs/phy_1/camera_to_dsi_display_phy.area`，时序来自同目录的 `final_timing.rpt`。工程与文件版本仍为 v2.7。本次文档核对没有重新运行综合、布局布线或时序分析。
