# 系统概览

系统使用 PH1P35A 开发板与 SC520 摄像头，将视频处理和交互控制结合起来。FPGA 侧承接视频数据处理及相关硬件功能，MCU 固件负责菜单、任务协调及控制逻辑。此处只介绍功能分工，不提供内部接口和代码结构。

| 部分 | 主要职责 |
|---|---|
| 摄像头及采集链路 | 获取场景图像并送入后续处理 |
| 图像处理 | 提供画面增强、处理与显示所需的数据 |
| 目标分析 | 提供目标检测、运动检测及跟踪所需的信息 |
| MCU 控制与交互 | 处理中文菜单、功能选择和任务协调 |
| 显示与提示 | 输出图像、目标框、运行状态及语音提示 |
| 舵机机构 | 执行当前跟踪模式对应的方向调整 |

视频显示、目标分析和机构控制有各自的处理节奏。屏幕刷新率、检测结果更新速度与舵机响应速度不是同一个指标；内部视频延迟也不能直接代替整机响应时间。

本仓库展示概念架构，并公开[演示所需的外设接线](HARDWARE.md)、[板上菜单操作](BOARD_OPERATION.md)及[布局布线摘要](IMPLEMENTATION.md)。内部寄存器、通信格式、模型结构、缓存布局、详细时序路径和关键算法参数仍未公开。完整工程依赖相应厂商平台及授权组件，不能用本仓库中的说明文件直接构建。
