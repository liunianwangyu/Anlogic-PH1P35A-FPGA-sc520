# 演示说明

演示视频已完成拍摄剪辑，仓库尚未提供观看链接和实物照片。现有视频是否包含自动寻找、渐变聚光和本轮中文菜单，应以实际视频内容为准。功能验证范围见[验证情况说明](VALIDATION.md)。

## 建议的展示顺序

| 顺序 | 展示内容 | 观众关注点 |
|---|---|---|
| 1 | 实物整体、摄像头和 HDMI 画面 | 确认是实物运行，交代输入与输出 |
| 2 | 中文菜单与图像处理切换 | 看清操作过程与画面变化 |
| 3 | 目标检测、运动检测，逐项展示 | 观察目标框及分析结果 |
| 4 | 自适应目标跟踪与双轴机构 | 同时拍到目标移动、显示画面和机构响应 |
| 5 | 自动寻找 | 先锁定目标，再演示目标丢失、局部双轴扫描及重新跟踪 |
| 6 | 目标聚光 | 对比开启和关闭时的框内画面、框外渐变及原图对比 |
| 7 | 语音提示与运行状态 | 展示交互效果与诊断信息 |

这是一份拍摄建议，不代表组委会规定的视频格式或时长。具体要求以赛事通知为准。

## 补充视频时应写明

- 视频标题、可访问的观看链接及拍摄日期。
- 对应工程版本、演示了哪些功能，以及主要场景条件。
- 视频如经过剪辑、加速或使用仿真画面，应明确标注。

请使用自己有权公开的画面与声音。拍摄前检查电脑桌面、终端、板卡标签、二维码和背景，避免包含账号、源码、内部路径、个人信息或非公开资料。不要提供指向完整工程的网盘链接。

视频可使用合适的平台提供观看入口，前提是满足赛事要求且评审能正常访问。如入口需要登录、密码或即将过期，应提前处理。仓库中不附带视频平台账号凭据。

## 补充图片

经检查的照片可以放入 `assets/`，并在本页或首页用相对路径引用。每张图配一行说明，注明是实物照片、屏幕截图还是仿真图。当前 `assets/` 中只有说明文件。
