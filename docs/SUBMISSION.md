# 竞赛评审阅读指引

本项目面向嵌入式竞赛 FPGA 赛道·安路二赛道。项目名称为“基于 FPGA 的实时视觉处理与目标跟踪系统”，工程版本 v2.7。

## 公开材料

建议按以下顺序阅读：

1. [项目首页](../README.md)：了解项目目标、功能及公开范围。
2. [功能介绍](FEATURES.md)与[系统概览](SYSTEM_OVERVIEW.md)：了解操作和功能分工。
3. [验证情况](VALIDATION.md)：区分参赛者的实板确认与既有自动化记录。
4. [演示说明](DEMO.md)：查看演示入口及材料状态。

本仓库为说明与展示材料，核心源码、模型和可烧录文件未公开，无法独立编译或复现完整系统。需要非公开材料时，由参赛团队按照组委会指定方式提交。

## 提交边界

本仓库不是组委会的官方规则说明，也不表示仅提交仓库链接就完成全部参赛流程。仓库链接、报名信息、技术报告、视频和其他附件是否必须提供，应以正式通知为准。

当前公开材料不列出个人证件、学号、联系方式或其他身份信息。赛事报名所需的身份信息应填入指定系统，不默认放在公开仓库中。
